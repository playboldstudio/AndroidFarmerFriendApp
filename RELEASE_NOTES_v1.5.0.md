# Farmer Friend v1.5.0

• Stable release — fixes a release-build crash on Market, Schemes, Disease & CropNotes screens (offline cache removed)
• App-logo notifications — every push now shows the Farmer Friend logo, not a generic system icon
• Profile validation — name capped at 30 characters with a live counter; mobile number field hardened (leading +91 handled correctly, proper error messages)
• Scroll-aware FAB — the share-rate-card button in Market slides away on scroll-down (Gmail-style) and reappears on scroll-up
• Compose performance — reduced recomposition, derived-state optimisation, and duplicate-allocation cleanup
• Adaptive tablet layout — content column widens on tablets
• Update prompt — in-app update shown as a centered English dialog
• Google sign-in — clearer message when no Google account is available
• 11 Indian languages supported
• Bug fixes and performance improvements
